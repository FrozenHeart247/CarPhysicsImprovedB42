# Сравнение Realistic Car Physics, CPI V1 и CPI V2

| Область | Старый Realistic Car Physics | CPI V1 (Legacy) | CPI V2 |
|---|---|---|---|
| Интеграция | Полная замена `zombie.core.physics.CarController`, `WorldSimulation`, `ItemContainer` | ZombieBuddy advice, отдельное состояние, без классов `zombie.*` | ZombieBuddy advice и независимая новая модель |
| КПП | Собственные фиксированные ряды 3/4/5 передач, гидротрансформатор | Та же архитектура расчёта; ручной селектор исправлен до `R-N-1-...` | Единая новая модель двигателя/сцепления/КПП |
| Разгон | `enginePower`, torque curve, converter slip, traction cap | Переписано независимо по тем же наблюдаемым формулам и коэффициентам | Силовая модель V2 с весом, состоянием и геометрией |
| Накат | Квадратичный drag плюс road/offroad rolling resistance | Перенесён тот же тип сопротивлений и дефолтные коэффициенты | Новая калибровка сопротивлений и engine braking |
| Burnout | Разница расчётной скорости колеса и скорости кузова | Traction cap, отдельная величина wheelspin, визуальный rear-wheel spin и собственный звук | Slip по ведущей оси, burnout/drift/understeer |
| Руление | Скоростные factor/centering/snapback | Перенесено как отдельная клиентская настройка | Новая геометрия руля, боковые силы и стабилизация |
| Шины | Среднее давление/состояние и `wheelFriction` | То же семейство факторов без глобальной перезагрузки `VehicleScript` | Состояние каждой шины, оси, нагрузка и подвеска |
| Столкновения | Масштабирование накопленных импульсов растений/зомби/трупов и 0.08-секундный wheel-impulse cooldown | Точечные патчи к текущим B42.20.4 методам; горизонтальная потеря скорости на трупе отделена от вертикального подлёта, для подлёта восстановлен изолированный cooldown | По умолчанию полностью ванильная collision response |
| Багажник | Полная замена `ItemContainer.getCapacity()` и таблица автомобилей | OnExit-патч `getCapacity()` только при включённом beta-параметре и зарегистрированных данных | Не меняется |
| Модовые машины | Требовали таблицу параметров, KI5-патч сливал данные в `RCP_VehicleValues` | Любая машина работает из `VehicleScript`; API позволяет уточнить HP/массу/cargo | Нативный generic snapshot `VehicleScript`, опциональные layout overrides |
| Звук двигателя | Опционально отключал ванильные события и запускал собственные emitters | Ванильный звук не перехватывается; только новый tire loop | Ванильный двигатель плюс новый tire loop |
| Следы шин | Не являлись частью исходного RCP | Собственные сгенерированные текстуры; временный клиентский Java-буфер рисуется в штатном floor-decal pass только при подтверждённом slip | Отложено |

V1 предназначен для прямого A/B-сравнения ощущения со старым модом. V2 остаётся основной новой веткой. Эти моды нельзя включать одновременно, потому что оба отправляют итоговую команду одному `CarController`.
