# Provenance

Car Physics Improved V2 is an independent clean-room rewrite.

- No classes, bytecode, source, assets, sounds, or identifiers from the removed Realistic Car Physics release are included.
- The abandoned mod is treated only as a user-observed behavior reference.
- ZombieBuddy integration follows its public annotation/API contract and an independently inspected working Workshop layout.
- The physics formulas, adapter, tests, Lua configuration, and documentation in V2 were authored for this project.

Renaming variables or methods in third-party code would not create an independent implementation and is explicitly outside this project.
