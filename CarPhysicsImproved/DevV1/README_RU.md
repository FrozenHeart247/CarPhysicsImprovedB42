# Car Physics Improved V1 (Legacy)

Отдельная реализация старого типа автомобильной физики для Project Zomboid B42 и ZombieBuddy. V1 не содержит и не загружает классы `zombie.*`; установленная игра остаётся источником ванильных классов, а V1 применяет точечные патчи после их загрузки.

Тестовый Mod ID: `CarPhysicsImprovedV1B42`. Java package: `pzmod.carphysicsimproved.v1`. Одновременное включение с `CarPhysicsImprovedB42` (V2), `RoadcraftDynamicsB42` или `RealisticCarPhysics` запрещено через `mod.info`.

## Что перенесено

- старые 3/4/5-ступенчатые передаточные ряды и выбор передачи по оборотам;
- гидротрансформатор, lockup/slip и ограниченный множитель тяги;
- общий расчёт для автоматической и ручной КПП; ручной селектор имеет `R-N-1-2-...`;
- ограничение тяги доступным сцеплением и burnout при превышении лимита;
- состояние и давление шин, дождь, снег и бездорожье в сцеплении;
- квадратичное аэродинамическое сопротивление и старые линейные сопротивления качению;
- старое прогрессивное руление и возврат руля;
- отдельные коэффициенты импульса растений, зомби и трупов;
- опциональная вместимость багажника для машин, зарегистрированных через API;
- универсальный fallback из `VehicleScript` для любой модовой машины.

## Осознанно не перенесено как старый файл

- полные замены `CarController`, `WorldSimulation` и `ItemContainer`;
- аудиофайлы и Lua/Java-файлы Realistic Car Physics;
- старый KI5-список параметров. Вместо него V1 предоставляет API регистрации;
- экспериментальная замена звука двигателя. Она выключала ванильные события и была связана с пропажей звука. V1 оставляет звук двигателя игре и добавляет только собственный loop шин;
- собственные реализации автозапуска и буксировки: соответствующие B42.20.4 механики остаются ванильными.

## API модовых машин

```lua
require "CarPhysicsImprovedV1/API"

CarPhysicsImprovedV1.registerVehicleSpec(
    "MyMod.MyVehicle",
    250,  -- horsepower
    1650, -- mass kg
    320   -- cargo kg; используется только при включённом TrunkOverhaul
)
```

Без регистрации машина всё равно поддерживается: мощность, масса, тип, число передач, тормоза, steering clamp и offroad efficiency читаются из её `VehicleScript`.

## Сборка и проверка

```powershell
.\DevV1\test.ps1
.\DevV1\package.ps1
```

По умолчанию скрипты используют игру в `F:\SteamLibrary\steamapps\common\ProjectZomboid` и JDK в `D:\JavaSDK\bin`; оба пути можно передать параметрами. Релизный ZIP содержит только V1, `Contents` и `workshop.txt`.
