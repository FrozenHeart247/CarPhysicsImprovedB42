# Generated tire-mark asset

`CPI_V1_TireTrack_Source.png` was generated specifically for Car Physics Improved V1.

Prompt:

> Create an original game texture asset for a top-down isometric survival game: a single straight tire skid mark segment, centered and running vertically from bottom edge to top edge so repeated copies connect seamlessly. Transparent background with true alpha; only the rubber mark is visible. Dark charcoal-black rubber, narrow car-tire contact patch, irregular feathered edges, subtle broken tread/contact grain and varied opacity, slightly stronger in the center, no asphalt, no road, no ground color, no lighting scene, no drop shadow beyond the rubber, no perspective, no text, no logo, no watermark. Orthographic flat decal texture, tileable vertically, generous transparent margin left and right, square 1024x1024 PNG suitable for downscaling to 128x128.

The returned 1254x1254 ARGB source was cropped to its central tread, resized onto a
64x64 transparent base, and mechanically rotated in 11.25-degree increments. The
16 runtime variants are shipped under `media/textures` and are not copied from any
reference mod.
